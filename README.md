# NarrativeForge 最小选句依据组件

纯 Python 标准库实现。每次根据已计算的阈值事实与有序规则模板，
生成一个叙述句及其可审计证据（能固定选中结果的最小事实集合）。

## 运行测试

```sh
python3 -m unittest test_narrativeforge -v
```

## 接口

```python
import narrativeforge as nf

result = nf.generate(facts, template)
# result.rule_id  选中规则 id（全部条件为假时为默认句 id）
# result.sentence 对应句子
# result.evidence 证据事实列表，按 id 升序，每项保留输入的布尔值与引用说明
```

- 事实：`{"id": str, "value": bool, "citation": str}`，id 唯一；
  引用说明原样保留，组件不重新计算统计量。
- 模板：`{"rules": [{"id", "condition", "sentence"}], "default": {"id", "sentence"}}`。
- 条件 JSON 树：`{"fact": "<id>"}`、`{"and": [...]}`（非空）、`{"or": [...]}`（非空），
  不支持 `not`；事实可跨规则或同一条件内重复引用。
- 选择语义：第一个条件为真的规则；全部为假时选默认句。

## 证据性质

固定证据中事实的本次布尔值，让其余事实任意、独立取真或假，
最终选中的规则 id 始终不变。因此证据不仅证明命中条件，还排除了所有更早规则；
默认句的证据证明全部规则均不命中。不利用指标间的业务关联。

在所有满足该性质的证据集合中返回事实数最少者（同一事实按 id 只计一次）；
并列时将各集合 id 升序排列，取字典序最小集合，并按此顺序输出。

## 复杂度与最坏情况

设 n 为模板条件实际引用到的事实数（未被引用的事实不影响结果，直接忽略），
m 为规则数，L 为单条条件树的最大节点数。

- 证据搜索按集合大小递增枚举子集，并对每个候选子集枚举其余事实的全部赋值：
  最坏时间 O(3^n · m · L)（每个事实在"子集内 / 自由赋值两次"间分配，
  即 ∑ C(n,k)·2^(n−k) = 3^n 次结果计算，每次 O(m·L)）。
- 空间 O(n + m · L)（不计输入）。
- 最坏情况出现在证据必须包含几乎全部事实时（例如默认句且各规则条件
  分别依赖不同事实），此时枚举不可约。该组件定位为最小可审计实现，
  适用于小事实规模；n 较大时需要引入 SAT/符号化方法，不在本组件范围内。
